# Лабораторная работа: Сервер интернет-радио на ASP.NET Core

Полнофункциональный сервер потокового аудиовещания (HTTP Streaming) на платформе **ASP.NET Core (Minimal API)** с веб-интерфейсом радиоплеера на HTML5 `<audio>`.

---

## 📋 Реализованные требования и функционал

1. **HTTP Streaming эндпоинт (`/stream/{station}`)**:
   - Отдача аудиопотока в режиме `Transfer-Encoding: chunked`.
   - MIME-тип: `Content-Type: audio/mpeg`.
   - Отсутствие заголовка `Content-Length`.
   - Отключение буферизации (`Cache-Control: no-cache`, `X-Accel-Buffering: no`).
   - Pacing (контроль темпа потока по битрейту) для эмуляции непрерывного реального радиоэфира.

2. **Несколько радиостанций**:
   - `rock` — «Рок-Волна» (`/stream/rock`)
   - `jazz` — «Джаз-Кафе» (`/stream/jazz`)
   - `pop` — «Поп-Хит» (`/stream/pop`)
   - Легко расширяется добавлением папок в `wwwroot/audio/{station_name}`.

3. **Метаданные станций (`/stations`)**:
   - JSON-эндпоинт со списком всех станций, количеством активных слушателей и названием текущего трека.

4. **Параллельные клиенты и счётчик онлайн**:
   - Каждый слушатель получает собственный независимый `FileStream`.
   - Атомарный счётчик слушателей на базе `Interlocked.Increment` / `Interlocked.Decrement`.
   - Потокобезопасный `StationManager`.

5. **Обработка отключений и жизненного цикла**:
   - Реагирование на `HttpContext.RequestAborted` (`CancellationToken`).
   - Перехват `OperationCanceledException` и `IOException` при разрыве соединения.
   - Корректное освобождение ресурсов и гарантированное уменьшение счётчика онлайн в блоке `finally`.

6. **Веб-плеер (HTML5 + CSS + JavaScript)**:
   - Адаптивный современный интерфейс в тёмной теме.
   - Индикатор прямого эфира (LIVE) и анимация аудио-эквалайзера.
   - Выбор станций кликом по карточкам с обходом кэша (`?t=${Date.now()}`).
   - Автоматический опрос метаданных каждые 3 секунды.
   - Регулятор громкости и кнопка Mute.

7. **Серверная панель управления (Admin Dashboard)**:
   - Доступна по адресу `/admin` (или `http://localhost:5000/admin`).
   - Телеметрия в реальном времени: Uptime, RAM (память процесса .NET), суммарный объём переданного аудио-трафика, общее число активных слушателей.
   - Управление станциями: принудительное переключение трека (Skip), перечитывание папки с диска (Reload), загрузка новых MP3/OGG файлов через браузер.
   - Создание новых радиостанций на лету через форму без перезапуска сервера.
   - Живой журнал активности (Activity Log): фиксация подключений клиентов с IP-адресами, отключений и действий администратора.

8. **Автономность и демо-треки**:
   - При первом запуске автоматически генерируются валидные тестовые MP3-треки (MPEG-1 Layer 3, 128 kbps, Joint Stereo с ID3v2.3 тегами) в директориях станций.
   - Для добавления своей музыки достаточно положить `.mp3` или `.ogg` файлы в `wwwroot/audio/{station}/` или загрузить через панель управления.

## 🚀 Запуск проекта

1. Перейдите в каталог проекта:
   ```bash
   cd f:\antigravity\radio
   ```

2. Запустите сервер:
   ```bash
   dotnet run --urls "http://localhost:5000"
   ```

3. Доступные веб-интерфейсы:
   - **Веб-плеер слушателя:** [http://localhost:5000/](http://localhost:5000/)
   - **Панель управления сервером:** [http://localhost:5000/admin](http://localhost:5000/admin)

## 🧪 Проверка и тестирование через CLI

### 1. Получение списка станций:
```bash
curl -s http://localhost:5000/stations
```
Пример ответа:
```json
[
  { "id": "rock", "name": "Рок-Волна", "listeners": 0, "currentTrack": "track1.mp3" },
  { "id": "jazz", "name": "Джаз-Кафе", "listeners": 0, "currentTrack": "track1.mp3" },
  { "id": "pop", "name": "Поп-Хит", "listeners": 0, "currentTrack": "track1.mp3" }
]
```

### 2. Проверка заголовков потока:
```bash
curl -v -N "http://localhost:5000/stream/rock" --max-time 2 -o NUL
```
В заголовках ответа будут:
```http
HTTP/1.1 200 OK
Content-Type: audio/mpeg
Transfer-Encoding: chunked
Cache-Control: no-cache, no-store, must-revalidate
X-Accel-Buffering: no
```

### 3. Проверка поведения при 404:
```bash
curl -I http://localhost:5000/stream/nonexistent
# Возвращает HTTP/1.1 404 Not Found
```
